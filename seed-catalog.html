FeMOS Catalog Seeder

One-time developer tool — populates Institutions → Campuses → Courses in Firestore.

This is a starter catalog only (a handful of sample courses per campus), not the full ~50-course list for each institution. Use admin.html afterwards to add every remaining course. Running this twice will just overwrite the same starter documents (safe to re-run).
